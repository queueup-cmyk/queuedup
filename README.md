# QueuedUp
Helping Discord gaming communities organise tournaments, player signups, waiting lists and event reminders.

## What is QueuedUp?

QueuedUp is a project exploring how to make organising gaming tournaments and events on Discord easier.

## The Problem

Gaming community organisers may have to manage player signups, team lists, cancellations, waiting lists and reminders manually. This can become confusing and time-consuming.

We need to speak to real organisers to find out which problems actually matter.

## Our Initial Idea

QueueUp could help organisers:
- Create and announce gaming events
- Collect player signups
- Manage waiting lists
- Handle cancellations
- Send event reminders

These are potential features, not confirmed requirements.

## Our Target Customers

Discord server owners, gaming community managers and tournament organisers who run regular gaming events.

## Our Business Model

Potential model: a free basic version with optional paid features if customers are willing to pay for them.

Possible starting price to test: 99 SEK per month.

This price and business model have not been validated.

## Current Stage

Day 1 — Customer research.

Our priority is to understand organisers' problems before building the product.

## Our Rule

Talk to potential customers, validate the problem, build a small prototype, test it and improve it based on feedback.
